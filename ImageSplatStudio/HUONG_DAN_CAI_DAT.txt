# ImageSplat Studio — Hướng dẫn cài đặt Windows

## ⚠️ QUAN TRONG

File **`ImageSplatStudio-Setup-0.1.0.zip` KHÔNG phải file Setup.exe!**

Bạn phải **GIẢI NÉN** trước, rồi chạy **`CaiDat.bat`**.

---

## Cách cài (3 bước)

### Bước 1 — Giải nén
1. Tải file `.zip` từ [Release](https://github.com/HieuPC03/ConstructionModelLibrar/releases/tag/imagesplat-v0.1.1)
2. **Click phải** → **Extract All...** / **Giải nén tất cả...**
3. Chọn thư mục, ví dụ: `C:\ImageSplatStudio\`

### Bước 2 — Chạy CaiDat.bat
1. Mở thư mục vừa giải nén
2. **Click phải `CaiDat.bat`** → **Run as administrator**
3. Đợi cài thư viện (2–5 phút lần đầu)

### Bước 3 — Mở app
- App tự mở sau khi cài xong
- Lần sau chạy **`ImageSplat Studio.exe`**

---

## Lỗi thường gặp

| Triệu chứng | Cách sửa |
|-------------|----------|
| Bấm file zip không chạy | **Giải nén** trước, không chạy trực tiếp file zip |
| "Windows protected your PC" | **More info** → **Run anyway** |
| Báo thiếu Python | Cài [Python 3.11](https://www.python.org/downloads/) — tick **Add to PATH** |
| Exe mở rồi tắt ngay | Chạy **CaiDat.bat** (Admin) trước |
| Admin vẫn không được | Giải nén ra `C:\ImageSplatStudio\` (tránh OneDrive/Desktop) |
