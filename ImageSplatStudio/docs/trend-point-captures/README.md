# Ảnh / ghi chú tham chiếu TREND-POINT Ver.11 (local)

Thư mục này dùng để lưu **screenshot và ghi chú** từ TREND-POINT đã cài trên PC Windows.

## Cách thêm

1. Chạy `scripts/capture-trend-point-reference.ps1` trên Windows  
2. Chụp màn hình theo checklist trong script  
3. Copy file `.png` vào đây  
4. Commit & push (hoặc đính kèm khi nhắn agent)

## File mong đợi

- `01-ribbon-tabs.png` … `08-trace-surface.png` (xem `../TREND-POINT-V11-LOCAL-REFERENCE.md`)
- `notes.md` — ghi chú thao tác, đường dẫn cài đặt
- `report-*.txt` — output tự động từ script PowerShell

**Không commit** file dữ liệu point cloud thật (LAS/PLY) — chỉ UI reference.
