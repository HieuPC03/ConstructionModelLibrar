  MEETING TRANSLATOR — Ứng dụng DESKTOP (không dùng trình duyệt)
═══════════════════════════════════════════════════════════════

■ KHUYẾN NGHỊ: CÀI APP DESKTOP (.exe)
──────────────────────────────────────────────────────────────
  Sau khi cài, mở cửa sổ riêng — KHÔNG cần Chrome/Edge.

  Bước 1 — Giải nén thư mục hoặc clone repo
  Bước 2 — Chạy:  install-desktop.bat
  Bước 3 — Sửa API key tại:
            %APPDATA%\meeting-translator-desktop\.env
            (lần chạy desktop lần đầu tự tạo; hoặc backend\.env khi dev)
  Bước 4 — Chạy:  CHAY-DESKTOP.bat

  Tạo file cài Setup.exe (chạy trên Windows):
    pack-desktop.ps1

  File .exe sau khi build:
    meeting-translator\dist\desktop\Meeting-Translator-Setup-1.0.0.exe

■ ĐƯỜNG DẪN
──────────────────────────────────────────────────────────────
  Thư mục app:     meeting-translator\
  Chạy desktop:    CHAY-DESKTOP.bat
  Cài lần đầu:     install-desktop.bat
  Zip portable:    dist\Meeting-Translator-v1.0.0.zip

  Dữ liệu trên máy bạn (sau khi chạy desktop):
    %APPDATA%\meeting-translator-desktop\
      .env              ← API key OpenAI / Gemini
      recordings\       ← Bản ghi hội thoại + transcript

■ YÊU CẦU
──────────────────────────────────────────────────────────────
  - Windows 10/11
  - Python 3.10+ (PATH)
  - Node.js 18 LTS
  - Internet khi dịch (OpenAI Whisper + GPT/Gemini)
  - OPENAI_API_KEY bắt buộc

■ TAI NGHE / LOOPBACK
──────────────────────────────────────────────────────────────
  Trong app desktop, cột trái:
    Loopback / Stereo Mix  hoặc  Chia sẻ tab cuộc họp
  Bật "Thêm micro" để ghi cả lời bạn nói.

■ PHIÊN BẢN TRÌNH DUYỆT (không khuyến nghị)
──────────────────────────────────────────────────────────────
  CHAY.bat + http://127.0.0.1:5173 — chỉ dùng khi debug.
